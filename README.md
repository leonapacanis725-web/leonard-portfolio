# Leonard Portfolio

A personal portfolio showcasing hands-on cybersecurity work, technical investigations, and independent technology projects.

**Live portfolio:** [Open the website](https://leonapacanis725-web.github.io/leonard-portfolio/)

## About

This portfolio documents a practical, project-based approach to learning and building in technology. The work focuses on investigating systems, analyzing evidence, documenting findings, and developing useful independent projects.
